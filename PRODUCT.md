# Product

## Register

product

## Users

Technical operators (DevOps engineers, SREs, architects, developers) managing AWS infrastructure. They use this during daily standups and quick status checks—rapid scanning, not deep analysis. Users value speed and clarity over decorative elements.

## Product Purpose

AWS NLP Assistant democratizes cloud infrastructure queries through natural language. Instead of jumping between AWS Console, CloudWatch, Cost Explorer, and CloudTrail, users ask questions in plain English and get human-readable answers. Success: non-technical questions get accurate, fast answers without console friction.

## Brand Personality

Friendly, modern, efficient. Approachable (not intimidating), but expert-grade and trustworthy. Feels alive and responsive, not sterile or bureaucratic.

## Anti-references

Monotone. Overly corporate. Sterile enterprise software. Cold, gray-only interfaces. Avoid the AWS Console's dense-information default; prioritize clarity and visual hierarchy over feature-completeness.

## Design Principles

1. **Clarity over features** — Every answer on screen should be scannable at a glance. A user standing up to report status should find the answer in under 1 second.
2. **Conversational confidence** — Chat feels natural and intelligent, not robotic. Thinking steps and skill indicators reassure the user that the system understood correctly.
3. **Information hierarchy** — Color and typography guide the eye to what matters now. Metrics pop; context doesn't distract.
4. **Modern craftmanship** — Tailwind-first, no design cruft. Precise spacing, intentional contrast, readable typography. Feels built, not generated.

## Accessibility & Inclusion

No stated specialized requirements. WCAG AA standard compliance is assumed.
